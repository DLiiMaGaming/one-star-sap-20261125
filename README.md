A [make.fun](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) entry for **"One Star, Written in Sap"** — a single one-line 1-star review written by a houseplant about the human who owns it.

## The entry

> One star. Bought me to 'bring life to the room,' then parked me in a sunless corner behind the sofa and tells guests the room feels dead because of me.

151 characters — one sharp irony, not a list: the plant was bought to bring life to the room, then blamed for the room feeling dead.

## How it works

`main.py` writes the fixed review string to `/output/entry.txt`. No randomness, no network, no input — every run produces byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
